# MediaTextWriter

社交媒体批量配字工具 - 快速为图片和视频添加文字内容

## 产品简介

MediaTextWriter 是一款专为社交媒体运营设计的批量配字工具。支持一键将文案批量写入图片或视频，极大提升内容制作效率。

### 核心特性

✅ **多种输入方式** - 文本、TXT、Excel、文件夹、拖拽上传  
✅ **三种匹配模式** - 单文复制、一一对应、随机匹配  
✅ **可视化编辑** - 拖拽调整文字位置，实时预览效果  
✅ **丰富样式配置** - 字体、颜色、边框、背景、透明度  
✅ **视频支持** - 自动处理视频，输出标准MP4格式  
✅ **智能换行** - 文本过长自动换行，适配画面宽度  

## 适用场景

- **电商运营**：批量制作商品展示图
- **短视频创作**：快速添加字幕或标题
- **营销推广**：生成批量广告素材
- **自媒体运营**：快速配字发布内容

## 快速开始

### 安装依赖

```bash
pip install -r requirements.txt
```

### 启动程序

```bash
python main.py
```

### 三步完成任务

1. **上传内容** - 拖入文案文件和媒体文件
2. **选择模式** - 单文复制/一一对应/随机匹配
3. **配置样式** - 调整字体、颜色、位置
4. **开始任务** - 一键生成所有文件

## 功能详解

### 输入方式

| 输入类型 | 说明 | 搭配要求 |
|---------|------|---------|
| 单条文本 | 直接输入框输入 | 需搭配媒体文件 |
| TXT文件 | 双回车分段 | 需搭配媒体文件 |
| Excel文件 | 图片列+文案列 | 可单独使用 |
| 文件夹 | 批量图片/视频 | 需搭配文案 |
| 单个媒体 | 图片或视频 | 需搭配文案 |

### 任务模式

**单文复制**  
一条文案应用到所有媒体文件  
适用场景：统一标题、水印

**单独对应**  
文案与媒体按顺序一一对应  
适用场景：图文匹配、有序内容  
⚠️ 数量不匹配时按最小值生成

**随机对应**  
文案随机分配到媒体文件  
适用场景：批量素材制作

### 样式配置

- **字体**：内置多款字体，支持导入自定义字体
- **字号**：10-200可调
- **颜色**：RGB颜色选择器
- **间距**：行间距、字间距独立调整
- **边框**：颜色、宽度可配置
- **背景**：纯色背景 + 透明度调节（0-100%）

### 可视化编辑

点击"预览编辑"进入可视化模式：
- 拖动文本框调整位置
- 缩放文本框调整大小
- 实时预览最终效果

## 输出说明

### 文件命名规则

```
媒体文件名前6位_文案前6字符.扩展名
```

示例：
- 媒体：`product_image_001.jpg`  
- 文案：`限时优惠 立即抢购`  
- 输出：`produc_限时优惠立.jpg`

### 输出目录

用户自定义输出目录，所有生成文件统一保存

### 视频处理

所有视频统一转换为 **MP4格式**，兼容性最佳

## 常见问题

**Q: 支持哪些图片格式？**  
A: JPG、PNG、BMP、WebP

**Q: 支持哪些视频格式？**  
A: MP4、AVI、MOV、MKV（输出统一为MP4）

**Q: 文本太长怎么办？**  
A: 自动换行，超出画面范围会自动分行

**Q: 如何导入自定义字体？**  
A: 点击"字体选择" → "导入字体" → 选择TTF/OTF文件

**Q: 文案和媒体数量不一致？**  
A: 系统取最小值生成，并显示红色警告提示
